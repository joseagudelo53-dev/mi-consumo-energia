📋 Documentación de Etiquetas HTML

Proyecto: Mi Consumo de Energía en Casa

Esta documentación lista todas las etiquetas HTML utilizadas en el proyecto con una descripción de su función.

Etiqueta Categoría Descripción y Función
📦 ESTRUCTURA BÁSICA DEL DOCUMENTO
<html> Estructura Elemento raíz que contiene todo el documento HTML.
<head> Estructura Contiene metadatos, títulos, referencias a estilos y scripts del documento.
<body> Estructura Contiene todo el contenido visible de la página web.
<meta> Metadatos Define metadatos como charset, viewport y descripción de la página.
<title> Metadatos Define el título que aparece en la pestaña del navegador.
<link> Enlaces Vincula recursos externos como hojas de estilos CSS al documento.
🗂️ CONTENEDORES Y ESTRUCTURA DE CONTENIDO
<header> Contenedor Semántico Define la cabecera de una página o sección con título e información introductoria.
<main> Contenedor Semántico Especifica el contenido principal de la página. Solo debe haber uno por página.
<section> Contenedor Semántico Agrupa contenido relacionado temáticamente en secciones lógicas.
<footer> Contenedor Semántico Define el pie de página con información como copyright y enlaces.
<nav> Navegación Contiene enlaces de navegación principales de la página.
<div> Contenedor Genérico Contenedor genérico para agrupar elementos y aplicar estilos CSS.
<figure> Contenedor Semántico Agrupa imágenes o contenido con su descripción (caption).
<figcaption> Contenedor Semántico Proporciona una descripción o título para el contenido de <figure>.
📝 TEXTO Y PÁRRAFOS
<h1> a <h6> Encabezados Define encabezados de diferentes niveles de importancia (h1 es el más importante).
<p> Párrafos Define un párrafo de texto.
<strong> Énfasis Destaca texto importante con mayor énfasis (generalmente en negrita).
<em> Énfasis Enfatiza texto con importancia (generalmente en cursiva).
<small> Texto Define texto de tamaño pequeño, como notas o comentarios adicionales.
<span> Contenedor Inline Contenedor inline para aplicar estilos a parte de un texto.
📋 LISTAS
<ul> Listas Define una lista desordenada (con viñetas).
<ol> Listas Define una lista ordenada (numerada).
<li> Listas Define un elemento dentro de una lista (ul u ol).
📊 TABLAS
<table> Tablas Define una tabla para mostrar datos en filas y columnas.
<thead> Tablas Agrupa encabezados de columnas en una tabla.
<tbody> Tablas Agrupa el cuerpo de datos en una tabla.
<tfoot> Tablas Agrupa el pie de página de una tabla (totales, resúmenes).
<tr> Tablas Define una fila en una tabla.
<td> Tablas Define una celda de datos en una fila de tabla.
<th> Tablas Define una celda de encabezado en una tabla.
<caption> Tablas Proporciona un título o descripción para una tabla.
📋 FORMULARIOS E INPUTS
<form> Formularios Define un formulario para recopilar datos del usuario.
<fieldset> Formularios Agrupa elementos relacionados en un formulario.
<legend> Formularios Proporciona un título o descripción para un fieldset.
<label> Formularios Define una etiqueta para un elemento de entrada de formulario.
<input> Inputs Define un campo de entrada (texto, número, email, fecha, archivo, etc.).
<textarea> Inputs Define un área de texto multi-línea para entrada de datos.
<select> Inputs Define una lista desplegable para seleccionar opciones.
<option> Inputs Define una opción dentro de un select o datalist.
<button> Botones Define un botón clicable (submit, reset, o button).
🖼️ MULTIMEDIA
<img> Media Inserta una imagen en la página.
<a> Enlaces Define un hipervínculo a otra página o recurso.
⚙️ OTRAS ETIQUETAS
<script> Scripts Incluye código JavaScript para agregar funcionalidad interactiva.
<style> Estilos Define estilos CSS directamente en el documento HTML.
<rowspan> / <colspan> Atributos de Tabla Permite que una celda de tabla abarque múltiples filas o columnas.
📌 Notas importantes:
  • Etiquetas semánticas: Las etiquetas como <header>, <main>, <section>, etc., mejoran la accesibilidad y el SEO.
  • Validación HTML: Todo el proyecto ha sido validado con el W3C HTML Validator.
  • Atributos comunes: class, id, style, name, type, required, placeholder, etc.
  • Bootstrap: Se utiliza Bootstrap 5.3.3 para estilos y componentes responsivos.
